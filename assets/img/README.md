# assets/img —— 壁画长卷

放 **1 张** AI 生成的贵州人间长卷墙画。

| 项 | 要求 |
| --- | --- |
| 文件名 | `scroll-guizhou.jpg` |
| 比例 | **6:1**（推荐 6144×1024 或 7680×1280） |
| 格式 | JPG（质量 ~85）或 WebP |
| 体积 | ≤ 3MB |

放好后，把 `js/config.js` 里的 `SCROLL.image` 从 `null` 改成 `'assets/img/scroll-guizhou.jpg'`。

6 个彩蛋场景要画在长卷的哪些横向位置上，见 [`docs/ASSETS.md`](../../docs/ASSETS.md) 第一节。
