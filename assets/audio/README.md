# assets/audio —— 彩蛋音效

放 **6 个**点亮彩蛋时的提示音。

| 文件 | 对应彩蛋 |
| --- | --- |
| `01-tongren.mp3` | 铜仁古城 |
| `02-dongzhai.mp3` | 黔东南侗寨 |
| `03-fengyuqiao.mp3` | 风雨桥 |
| `04-jiaxiulou.mp3` | 甲秀楼 |
| `05-zhenyuan.mp3` | 镇远古镇 |
| `06-fanjingshan.mp3` | 梵净山 |

## 格式要求

MP3，1~2.5 秒，≤ 200KB，峰值归一化到 -3dB 左右。

**建议用清亮的钟 / 磬 / 铃，6 个音高依次升高**，这样 6 个全部点亮时的收尾和弦才收得住。
五声音阶（宫-商-角-徵-羽-宫）最稳。

现在没有素材时，`js/audio.js` 会用 WebAudio 现场合成钟磬声，
音高是 `349.23 × 1.1225^n`（n = 0~5），可以照着这个调。
