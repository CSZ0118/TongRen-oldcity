## 格式要求

**MP4 / H.264 + AAC**，1920×1080，4~8 秒，≤ 8MB，建议静音导出。

剪映：`导出 → MP4 → H.264 → 1080P / 30fps`。**不要用 H.265**（部分浏览器不支持）。

## 兜底测试片是什么

`selftest/cc0-testclip.mp4` 是 MDN 的 CC0 示例素材（960×540 / 5.05s）。
它的作用是：6 段真视频还没到位时，让「点彩蛋 → 播视频」这条链路依然可测、可演示、断网也能跑。
Day2 真素材到位后**保留它**，新人上手和故障排查都用得上。

放好素材后：`npm run dev` → 打开 `http://127.0.0.1:5173/video-test.html` 自查。
