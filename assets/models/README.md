# assets/models —— 3D 建筑

放 **6 座**天宫建筑的 `.glb` 模型。

| 文件 | 建筑 | 造型要点 |
| --- | --- | --- |
| `01-tongren-nantianmen.glb` | 南天门式城楼 | 台基 + 门洞 + 楼身 + 重檐 + 宝顶 |
| `02-dongzhai-gulou.glb` | 天宫鼓楼，飞檐入云 | 多层密檐往上收，顶上一颗宝珠 |
| `03-fengyuqiao-langqiao.glb` | 天宫廊桥，横跨云海 | 横跨的长廊 + 两端桥墩 |
| `04-jiaxiulou-louge.glb` | 天宫楼阁，浮于云面 | 三层飞檐 + 石台 |
| `05-zhenyuan-shangong.glb` | 天宫山坡，依云而建 | 坡地上三间殿宇，高低错落 |
| `06-fanjingshan-jinding.glb` | 天宫金顶，云海环绕 | 双峰 + 峰顶小殿 |

## 格式要求

- **`.glb` 单文件**（贴图内嵌），不要 `.gltf` + 外部贴图
- ≤ 3MB / 个
- 面向 **+Z**，Y 轴朝上
- 材质用 PBR（metallic-roughness）；前端会叠一层暖色自发光，金属度高的瓦面效果最好
- **尺寸和原点不用纠结** —— 前端会自动归一化：高度缩放到屏幕高度的 42%、水平居中、底面贴地
- 不需要做动画，升起 / 自转 / 悬停浮动都是前端控制的

> 只建这 6 座建筑，**不做场景、不做地形**。
> 现在页面上看到的是前端用基础几何体拼的占位版本，可以用来自查造型方向。
