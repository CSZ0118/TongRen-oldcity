# 素材交付规范

> 给 **计科B（视频/音频）** 和 **建筑同学（3D）**。
> 按这里的文件名和格式交付，页面会自动接上，**前端一行代码都不用改**。

---

## 零、最重要的一句话

文件名必须**逐字符**对齐 `js/config.js` 里的路径。
放错一个字，页面就会当作"素材还没到"，然后默默用占位内容顶上，而且不会报错。

放完之后这样自查：

```bash
npm run dev
# 打开 http://127.0.0.1:5173/video-test.html   → 看视频到位情况
# 打开 http://127.0.0.1:5173/?debug=1           → 看全部素材（视频/模型/音效）到位情况
```

自检面板会逐条列出「有 / 缺」。

## 二、6 段彩蛋视频（计科B）

| 项 | 要求 |
| --- | --- |
| 路径 | `assets/video/01-tongren.mp4` 等（见下表） |
| 格式 | **MP4 / H.264（AVC）+ AAC** —— 唯一全平台都稳的选择 |
| 分辨率 | 1920×1080（或 1280×720） |
| 时长 | **4~8 秒**，太短看不出"长出来"，太长打断节奏 |
| 体积 | ≤ 8MB / 段 |
| 内容 | 对应的天宫建筑从壁画里"长出来"的过程：先是一点微光 → 结构升起 → 华彩定格 |
| 音轨 | **建议静音导出**。音效由 `assets/audio/` 单独负责，视频自带声音会跟音效打架 |

### 文件名

| 彩蛋 | 视频文件 |
| --- | --- |
| 1 铜仁古城 | `assets/video/01-tongren.mp4` |
| 2 黔东南侗寨 | `assets/video/02-dongzhai.mp4` |
| 3 风雨桥 | `assets/video/03-fengyuqiao.mp4` |
| 4 甲秀楼 | `assets/video/04-jiaxiulou.mp4` |
| 5 镇远古镇 | `assets/video/05-zhenyuan.mp4` |
| 6 梵净山 | `assets/video/06-fanjingshan.mp4` |

### 剪映导出设置

`导出` → 格式选 **MP4**，编码 **H.264**，分辨率 1080P，帧率 30，码率 8~12 Mbps。

> 已实测本机浏览器支持情况（`video-test.html` 第 3 块会实时显示）：
> MP4/H.264 ✅、WebM/VP9 ✅、MP4/H.265 ⚠️（部分浏览器不支持，**不要用 H.265**）。

## 三、6 个音效（计科B）

| 项 | 要求 |
| --- | --- |
| 路径 | `assets/audio/01-tongren.mp3` 等 |
| 格式 | MP3（128kbps 以上） |
| 时长 | **1~2.5 秒** |
| 体积 | ≤ 200KB |
| 内容 | 点亮那一刻的提示音。建议用**清亮的钟 / 磬 / 铃**，6 个音高依次升高（五声音阶最稳：宫-商-角-徵-羽-宫） |
| 峰值 | 归一化到 -3dB 左右，别削波 |

文件名把 `assets/video/xx.mp4` 换成 `assets/audio/xx.mp3` 即可（序号和名字完全一致）。

> 6 个音高依次升高，全部点亮时的和弦才收得住。
> 现在没素材时前端会用 WebAudio 合成钟磬，音高是 `349.23 × 1.1225^n`，可以照着这个调。

## 四、6 座 3D 建筑（建筑同学）

| 项 | 要求 |
| --- | --- |
| 路径 | `assets/models/01-tongren-nantianmen.glb` 等 |
| 格式 | **`.glb`**（单文件，贴图内嵌）。不要 `.gltf` + 外部贴图，容易漏文件 |
| 体积 | ≤ 3MB / 个 |
| 单位/朝向 | 面向 **+Z**，Y 轴朝上 |
| 尺寸 | **不用管** —— 前端会自动归一化：高度缩放到屏幕高度的 42%，水平居中，底面贴地 |
| 原点 | 建议放在**底面中心**（不是的话前端也会自动纠正，但自己放对更省事） |
| 材质 | 用 **PBR（metallic-roughness）**。前端会给所有材质叠一层暖色自发光，金属度高的瓦面效果最好 |
| 动画 | 不用做。升起 / 自转 / 悬停浮动都是前端控制的 |

## 六、常见问题

**Q：文件放进去了，页面还是显示占位内容？**
A：先看路径有没有写错（大小写敏感！GitHub Pages 是 Linux，`01-Tongren.mp4` 和 `01-tongren.mp4` 是两个文件）。
再看调试面板里的路径，跟你实际文件名逐字符比一遍。

**Q：视频放进去但播不出来？**
A：九成是编码问题。用 H.264 而不是 H.265/HEVC，容器用 MP4 而不是 MKV。
把文件拖到 `video-test.html` 第 6 块里当场试播，能播才说明编码没问题。

**Q：GLB 放进去但建筑大小/位置不对？**
A：前端会自动归一化高度和落脚点，所以基本不会错。如果确实怪，
检查模型原点是不是离几何体太远（比如原点在场景中心而模型在很远处），
用 Blender 的 `Object > Set Origin > Origin to Geometry` 修一下。

**Q：必须严格 6 个吗？**
A：现在是。想加第 7 个的话看 `docs/ARCHITECTURE.md` 的「改东西的入口」。
